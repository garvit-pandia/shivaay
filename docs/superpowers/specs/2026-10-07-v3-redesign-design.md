# V3 Redesign — "Editorial Motion × Living Route Map" (Design Spec)

**Date:** 2026-10-07 · **Branch:** `redesign/v3-2026` (off `redesign/immersive-2026`)
**Decisions (user, 2026-10-07):** direction **B + C hybrid**; motion engine **GSAP (ScrollTrigger, SplitText) + Lenis**;
**keep & refine** the Living-Yard 3D hero; **homepage first**, then roll the system to other routes after preview review.
**Constraints carried over:** light mode only, cream/teal/orange palette, 100% content parity, static export,
three.js stays inside `components/hero/scene/`.

## Concept

The immersive branch has strong metaphors but ~10 independent hand-rolled effects with no shared timing.
V3 keeps the brand world and replaces "fade-in on reveal" with **one choreographed motion system** and a
**living India route map** that tells the real business story: Ludhiana HQ → border → distribution → ports.

## Motion system

- **Lenis** smooth scroll, site-wide (`motion/SmoothScroll`), off under reduced motion; native touch scrolling
  untouched. Lenis drives `window.scrollTo`, so native `scroll` listeners (hero scrub, ScrollProgress) keep working.
  Route changes reset scroll immediately.
- **GSAP + ScrollTrigger + SplitText** (all free since 3.13) via `@gsap/react` `useGSAP` for cleanup. Imported only by
  homepage client components, so other routes don't pay for it until they adopt it. ScrollTrigger is synced to Lenis.
- Every effect sits inside `gsap.matchMedia("(prefers-reduced-motion: no-preference)")`; SSR/no-JS/reduced-motion
  markup is the finished, fully visible state (animations only use `from` states set at runtime).
- **Grain overlay:** fixed, `pointer-events:none`, ~4% SVG-noise (background-image, not mask — see lessons).

## Homepage (top → bottom)

1. **Hero (kept)** — Living Yard untouched; copy unchanged.
2. **Velocity marquee** — the stats band speeds up, reverses direction and skews slightly with scroll velocity.
3. **Services — stacked containers** — the 4 homepage services become large sticky cards that stack on scroll
   (CSS `position: sticky` with offsets); covered cards scale down and dim (scrubbed). Mobile: same, smaller offsets.
4. **Route map journey (new, replaces Leaflet on home)** — sticky SVG India map (Natural Earth, *India point of view*
   boundaries — official J&K/Ladakh depiction; generated by `scripts/gen_india_outline.py`) beside five chapter blocks
   (Ludhiana, Amritsar, Delhi, Mumbai, Mundra, from `cities`/`routes` in `data.ts`). Each chapter that becomes active
   zooms the map's viewBox, draws its route from Ludhiana, pulses the city, and shows its tag/services. After the last
   chapter, all routes are live with freight dots travelling them. LiveTicker sits on the map. Mobile: map sticky in the
   top ~42vh, chapters scroll beneath. Reduced motion: all routes drawn, full-corridor view.
5. **Process — horizontal track** — desktop pins the section and translates the 4 steps horizontally while a dashed
   route line draws and step counters tick; mobile is a vertical list with a drawing line.
6. **Why us** — sticky heading column; items reveal with line-masked text and hairline draws.
7. **Promise** — the mission sentence becomes big type whose words fill ink-on-scroll (scrubbed); Vision and
   Commitment as waybill cards.
8. **Testimonials** — conveyor kept; heading moved to the new text reveal.
9. **CTA** — teal panel expands from an inset rounded card to full-bleed as it enters (clip-path scrub); crates kept.

Removed from home: `RouteSpine` (the route map *is* the route now) and `HomeShell`. Leaflet `NetworkMap` stays in
the repo only if another route uses it.

## Pure helpers (unit-tested, `lib/journey.ts`, no React/three/aliases)

- `project(lng, lat)` — equirectangular, constants shared with the generator script.
- `arcPath(a, b, bend)` — quadratic-curve SVG path between two projected points.
- `fitViewBox(points, pad, aspect)` — viewBox that frames given points at an aspect ratio.
- `chapterViews` — per-chapter viewBox + route list derived from `cities`/`routes`.

## Phase 2 — inner routes (2026-10-07)

- **`PageHero`** (`components/motion/PageHero.tsx`) on every inner route: masked-line h1, kicker/intro rise, giant
  outlined ghost word drifting with scroll, route line drawing along the bottom edge with a marker. Asides hidden < 640px.
- **/services:** containers are craned in row by row (`ScrollTrigger.batch`: drop, cable swing, settle) and tilt to the
  pointer (`motion/tilt.ts`); gallery photos sit behind container doors that swing open; masked headings.
- **/contact:** live waybill on the form — tracking number + barcode derived from the typed manifest
  (`lib/radar.ts#waybillId/barcodeBars`, decorative/aria-hidden), completion meter, scan sweep on each keystroke;
  sending slams a CLEARED stamp and the card takes the hit. Office map opens as an iris (CSS scroll-driven).
- **/resources:** dossier cards with tabs + tilt (`TiltGroup`), PageHero on every sub-page.
- **/resources/ports:** customs radar — every ICD/CFS plotted by true range/bearing from Ludhiana using coordinates parsed
  from its Maps embed (7 of 8; one has only a search embed). SVG beam rotates via CSS; each blip pings with
  `animation-delay = bearing/360 × period`, so it lights as the beam passes (no JS loop). List hover/focus/open ↔ blip.
- **404:** digits drop like crates (bounce), then the stamp slams and the stage shakes.
